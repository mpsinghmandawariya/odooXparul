## 🐛 TROUBLESHOOTING

### Issue: Old UI showing
**Solution:** Clear browser cache (Ctrl + Shift + R) or use incognito mode

### Issue: Images not loading
**Solution:** Check internet connection (Unsplash requires internet)

### Issue: Database error
**Solution:** The database file exists in `database/traveloop.db`

### Issue: Port already in use
**Solution:** Change port in `run_premium.py` (line at bottom: `app.run(debug=True, port=5001)`)
